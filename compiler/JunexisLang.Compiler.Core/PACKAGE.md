# Junexis Compiler Core

Paczka zawiera wspólne typy diagnostyk i profili platform używane przez
bibliotekę `JunexisLang.Runtime` dla .NET. Jest jawną zależnością techniczną
pakietu Runtime, a nie podstawowym punktem wejścia dla autora aplikacji.

Publicznym narzędziem kompilacji pozostaje polecenie `junexis`.
